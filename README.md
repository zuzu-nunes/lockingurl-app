# LempiraFlow

Personal finance app in Honduran lempiras (budget, spending by category, net worth, goals, insights). A Home Screen web app: open the site in Safari on iPhone, tap Share, then Add to Home Screen.

Data stays on the device (localStorage). Use Settings, then Export backup, to save a copy.

Icons are generated by `python tools/make_icons.py`. Bump `VERSION` in `sw.js` on each release so phones pick up the update.
